
# Домашнее задание №2

Программа обрабатывает csv-файл с данными о сотрудниках

Функциональность:  
1. Показать иерархию команд (департаменты по командам)
2. Показать сводный отчет по департаментам: численность, мин/макс и средняя зарплата 
3. Сохранить сводный отчет в отдельный csv-файл  

Использованы только встроенные модули Python (`csv`) 
Все функции имеют docstring и аннотации типов.  

Запуск
python homework_2.py
