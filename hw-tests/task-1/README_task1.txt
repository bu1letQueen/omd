Задание 1. Тестирование функции encode с использованием doctest.

1. Описание
Файл morse.py содержит функции encode и decode, а также словарь соответствий LETTER_TO_MORSE.
В docstring функции encode добавлены тесты:
 - тест с корректной строкой 'SOS';
 - тест, проверяющий выброс исключения на недопустимом вводе;
 - тест с длинной строкой и примером использования директивы doctest.

2. Запуск doctest
Для запуска тестов необходимо выполнить команду:

    python3 -m doctest -o ELLIPSIS -v task-1/task_1.py

Пояснение:
 - ключ -m doctest запускает модуль doctest;
 - параметр -o ELLIPSIS включает поддержку многоточий в выводе;
 - флаг -v включает подробный вывод прохождения тестов.

3. Проверка результата
Если все тесты пройдены, в консоль выводится отчёт doctest,
в конце которого будет строка вида:

    3 passed and 0 failed.
