Задание 2 — Параметрический тест для decode (pytest)

1) Что тестируем
Файл morse.py (в корне проекта) содержит функции encode и decode.
Функция decode(morse_message: str) принимает строку с кодами Морзе, разделёнными пробелами,
и превращает их в буквы/цифры. Пробелы между словами не восстанавливаются — результат слитный.

2) Где лежат файлы
- Код: morse.py
- Тесты: test_morse.py (в корне проекта)
- Результат запуска: task-2/result_task2.txt

3) Как запустить тесты
Запускать из корня проекта (папка hw-tests):

    pytest -v test_morse.py

4) Ожидаемый результат
pytest должен показать, что тесты прошли (PASSED).
