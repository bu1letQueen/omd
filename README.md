# CountVectorizer

Реализация класса для преобразования текстов в векторы количеств слов.

## Описание

Класс `CountVectorizer` преобразует массив текстовых строк в числовые векторы, где каждый элемент вектора соответствует количеству вхождений определенного слова в текст.

## Особенности

- Создает словарь уникальных слов (features) из переданных текстов
- Поддерживает опциональное приведение слов к нижнему регистру
- Возвращает матрицу векторов количеств слов
