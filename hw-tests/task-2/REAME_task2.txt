Задание 2. Параметрический тест для функции decode.

1. Описание задания
Файл morse.py содержит реализацию функций encode и decode.
Функция decode(morse_message: str) принимает строку с кодами Морзе,
разделёнными пробелами, и преобразует каждый код в соответствующую
английскую букву или цифру. Пробелы между словами в процессе
декодирования не восстанавливаются — результат получается слитным.

В рамках задания необходимо было написать параметрический тест
с использованием pytest.mark.parametrize, который проверяет корректную
работу функции на нескольких различных входных данных.

2. Что покрывается тестами
Тесты проверяют следующие случаи:
 - декодирование базового примера (SOS);
 - декодирование строки, состоящей из цифр;
 - декодирование строки, представляющей два слова подряд
   (например, «MAI PYTHON» → «MAIPYTHON»).

Каждый из этих примеров включён в список параметров pytest.

3. Структура проекта
Тестовый файл расположен в каталоге task-2 и называется:

    test_decode.py

Файл morse.py расположен в корневой папке hw-tests.

Запуск pytest выполняется строго из директории hw-tests, чтобы импорт
from morse import decode работал корректно.

4. Как запустить тесты
Для запуска тестов выполните:

    pytest -v

Команда должна быть выполнена в каталоге:

    /Users/bulletqueen/Projects/omd/hw-tests
