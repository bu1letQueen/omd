
# Домашнее задание №2

Программа обрабатывает CSV-файл с данными о сотрудниках.  
Функциональность:  
1. Показать иерархию команд (департамент → команды).  
2. Показать сводный отчёт по департаментам: численность, мин/макс и средняя зарплата.  
3. Сохранить сводный отчёт в отдельный CSV-файл.  

Использованы только встроенные модули Python (`csv`).  
Все функции имеют docstring и аннотации типов.
